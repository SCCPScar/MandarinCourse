Chinese Characters — How to Learn Them 汉字

Characters look intimidating but follow patterns. There are about 50,000 total, but you only need ~2,000 for newspapers and ~3,500 for daily life. Most are combinations of simpler components.

Most characters are made of radicals — building blocks that hint at meaning. Learn ~100 radicals and you can decode thousands of characters.

💡 Memory tip: 好 (hǎo, good) = woman 女 + child 子. A woman with a child = good! Many characters have stories like this.

Stroke order matters — it affects how characters look when written quickly, and it's crucial for handwriting recognition on phones. Follow these universal rules:

The 8 Stroke Order Rules

  1. Top to bottom — 三 (sān, three): draw top line first, then middle, then bottom
  2. Left to right — 川 (chuān, river): draw left stroke first, then middle, then right
  3. Horizontal before vertical (when they cross) — 十 (shí, ten): horizontal first
  4. Enclosures before contents, close last — 国 (guó, country): frame → contents → bottom
  5. Center before sides (for symmetrical chars) — 小 (xiǎo, small): center stroke first
  6. Left-leaning strokes before right-leaning — 人 (rén, person): left stroke first
  7. Bottom horizontal stroke last — 王 (wáng, king): three horizontals + vertical, bottom horizontal last
  8. Right-to-left sweeping strokes last
📱 Practice tool: Install the app Skritter (skritter.com) for interactive stroke order practice. Free tier is sufficient for beginners.
💡 Modern shortcut: For work in China, you'll mainly type on a phone/computer using Pinyin input. You don't need perfect handwriting for professional work, but you need to recognize characters when reading.

Simplified (简体) vs Traditional (繁體)

For working in mainland China: learn Simplified. Traditional is used in Taiwan, Hong Kong, and Macau.

SimplifiedTraditionalPinyinMeaning
爱愛àilove
书書shūbook
说說shuōspeak
国國guócountry
车車chēcar / vehicle
门門méndoor / gate
长長cháng/zhǎnglong / grow
💡 Good news: If you learn Simplified first, Traditional will be ~70% familiar. Many characters are identical in both systems.
